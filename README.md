# 나만의 어항 · 금붕어 먹이 주기 🐟

순수 HTML / CSS / Vanilla JS 로 만든 캐주얼 3D 어항 웹앱.
빌드 도구·프레임워크 없이 **GitHub Pages 에 그대로 올리면 바로 동작**합니다.

어항 · 금붕어 · 장식은 `assets/` 폴더의 **원본 3D 렌더 이미지**를 그대로 사용합니다.
(기하 도형으로 다시 그리지 않고, 캔버스 픽셀 조작으로 배경만 제거해 스프라이트로 합성)

## 기능
- **먹이 주기**
  - 웹캠 모드: 손을 인식해 위치를 추적하고, **핀치(엄지+검지를 모으는) 제스처**로 그 위치의 물속에 먹이를 떨어뜨립니다. (MediaPipe Hands, CDN)
  - 폴백 모드: 웹캠을 켜지 않거나 권한을 거부하면 **물을 클릭**해서 먹이를 줍니다.
  - 먹이는 `deco.png` 의 **크리스탈(보석 조각)** 이미지로 그려지며, 금붕어가 가장 가까운 먹이를 향해 헤엄쳐 와 먹습니다.
  - 금붕어는 진행 방향에 따라 `fish.png` 의 **측면/정면 스프라이트를 자동 전환**합니다.
- **어항 커스텀**: 하단 팔레트에서 수초·조개·항아리·크리스탈·바위 동굴 등 10종 장식을 골라 어항에 배치하고, 드래그로 위치를 옮깁니다. 아래로 갈수록 살짝 흐릿·어둡게 처리해 **수심 깊이감**을 줍니다. (장식 더블클릭 → 개별 제거)
- **초기화**: 배치한 장식·먹이를 한 번에 모두 지웁니다.

## 파일 구성
| 파일 | 설명 |
|------|------|
| `index.html` | 마크업 + 어항/캔버스 레이어 + MediaPipe CDN 로드 |
| `style.css`  | 유리·조약돌 무드의 미니멀 UI |
| `script.js`  | 배경 제거 · 스프라이트 크롭 · 물고기 AI · 먹이 물리 · 손 인식 · 장식/초기화 |
| `assets/bowl.png` | 유리 어항 |
| `assets/fish.png` | 금붕어(측면 + 정면) |
| `assets/deco.png` | 수초·조개·크리스탈 등 10종(5×2) |

## 원본 이미지를 스프라이트로 쓰는 방법
원본 PNG 에는 배경(회색 글로우 / 어두운 그라디언트 / 핑크)이 **구워져(baked)** 있어
그대로 겹쳐 그리면 사각형 배경이 보입니다. 그래서 로드 후 `script.js` 에서:
1. `cutoutBackground()` — 테두리에서 시작해 **바로 옆 배경 픽셀과만 비교하며 확산**하는 flood-fill 로 배경만 투명 처리 (그라디언트를 따라가되 물체 경계의 급격한 색 변화에서 멈춤). 진주·크리스탈 같은 내부의 밝은 부분은 보존됩니다.
2. `keepMainBlobs()` — 격자로 자를 때 옆 칸에서 삐져나온 작은 조각을 연결요소 라벨링으로 제거.
3. `trim()` — 알파 기준으로 타이트하게 크롭.

## 로컬 실행
`file://` 로 열면 `getImageData` 와 웹캠이 막히므로 간단한 정적 서버로 여세요.
Node 가 있으면:
```bash
node .claude/serve.js
```
브라우저에서 `http://localhost:8779` 접속.

## GitHub Pages 배포
1. 이 폴더의 파일을 저장소 루트에 커밋/푸시합니다. (`assets/` 포함)
2. 저장소 **Settings → Pages → Branch: main / (root)** 선택 후 저장.
3. 발급된 `https://<user>.github.io/<repo>/` 로 접속.
   - 웹캠은 HTTPS 에서만 동작하는데 GitHub Pages 는 기본 HTTPS 라 문제없습니다.

> `.claude/` 폴더(launch.json, serve.js)는 로컬 프리뷰용이며 배포 동작에는 영향이 없습니다.
